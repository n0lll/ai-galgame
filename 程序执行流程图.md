## ⏱️ 时间估算（示例）

**假设文件大小：**
- 世界观小说：50 万字符（约 100-150 页）
- 恋爱小说：30 万字符（约 60-90 页）

**执行时间：**

| 阶段 | 操作 | 耗时 |
|------|------|------|
| 初始化 | 启动和检查 | 1-2 秒 |
| 世界观提取 | 42 块 × 并发 8 | **5-10 分钟** ⏱️ |
| 恋爱提取 | 25 块 × 并发 8 | **3-6 分钟** ⏱️ |
| 女主合成 | 1 次深度分析 | **30-60 秒** ⏱️ |
| 数据保存 | 写入 JSON | 0.5 秒 |
| **总计** | | **约 8-16 分钟** |

**主要耗时在 API 调用！**

## 🔑 关键点总结

### ✅ 程序会做的事情

1. **并行处理**：同时提取多个文本块（最多 8 个并发）
2. **智能聚合**：自动合并、去重、排序
3. **深度分析**：合成女主完整人设（需要全书线索）
4. **数据保护**：严格保留 `villian_type` 和 `possible_ending`

### 📊 预期输出

- **3 个 JSON 文件**（如果两个输入文件都存在）
- **所有数据严格符合** `src/models.py` 的模型定义
- **可以直接用** `WorldLore.model_validate_json()` 解析

### ⚠️ 注意事项

- **API 成本**：长篇小说会产生大量 API 调用
- **时间消耗**：主要取决于文件大小和 API 速度
- **网络要求**：需要稳定的网络连接
- **数据质量**：AI 提取可能有误差，建议人工检查
